# Toolbar

A container for a title, navigation, icons or actions: `mat-toolbar` styled through Helix tokens.

- Uses `surface-minimal` by default; the Material 2 `color` input isn't used.

Consumer supplies: the content. For the product shell's top bar, use the branded Header instead.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/toolbar.stories.ts` (`Components/Toolbar`). The top example is its **With Menu And Icons** story; the Playground below has that story file's controls.
