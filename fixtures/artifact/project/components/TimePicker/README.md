# TimePicker

A `mat-timepicker` on a `matInput` in a `mat-form-field`. Users type a time or pick one from a list.

- Requires a date adapter (e.g. `provideNativeDateAdapter()`).

Consumer supplies: the field and adapter; configure the interval and min/max.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/time-picker.stories.ts` (`Components/Time picker`). It shows the **Playground** story with that story file's controls.
