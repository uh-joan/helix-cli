# TextArea

A multi-line input: `<textarea matInput>` in a `mat-form-field`, styled by the Helix theme. Taller than a standard input; overflow wraps onto new lines.

- Shares the input's outline/filled styles, states and sizes (`hlx-input-small` / `-x-small`).

Consumer supplies: the label, rows and any validation.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/text-area.stories.ts` (`Components/Text area`). It shows the **Playground** story with that story file's controls.
