# Checkbox

A `mat-checkbox` styled by the Helix theme — for multiple selection or toggling a setting.

- States: checked, unchecked, indeterminate, disabled; `disabledInteractive` keeps a disabled box focusable (e.g. for a tooltip).
- Label position after (default) or before; selected fill is `components-primary-filled` (ink).

Consumer supplies: the label and bound value. Use radio buttons when only one option can be chosen.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/checkbox.stories.ts` (`Components/Checkbox`). The top example is its **States** story; the Playground below has that story file's controls.
