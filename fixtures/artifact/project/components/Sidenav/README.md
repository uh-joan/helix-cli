# Sidenav

A navigation drawer, `mat-sidenav` styled by the Helix theme.

- **Standard** drawers use `mode="side"` (pushes content); **modal** drawers use `over` or `push` with a backdrop.

Consumer supplies: the drawer links and content. Use `side` on wide screens, `over` on narrow ones.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/sidenav.stories.ts` (`Components/Sidenav`). It shows the **Playground** story with that story file's controls.
