# Paginator

Page controls for a data set, `mat-paginator` styled by the Helix theme.

- Needs `length` (total items) and `pageSize` (50 by default); optional page-size options and first/last buttons.
- Background is transparent (`--mat-paginator-container-background-color`).

Consumer supplies: the length, page size and page event handler.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/paginator.stories.ts` (`Components/Paginator`). It shows the **Playground** story with that story file's controls.
