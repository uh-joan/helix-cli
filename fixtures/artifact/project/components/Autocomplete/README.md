# Autocomplete

A text input with a filtered suggestion panel: `matInput` + `mat-autocomplete` in a `mat-form-field`, styled by the Helix theme. Type to filter.

Consumer supplies: the control and the option list (filtered as the user types). The panel reuses the menu surface and tokens.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/autocomplete.stories.ts` (`Components/Autocomplete`). The top example is its **Grouped** story; the Playground below has that story file's controls.
