# Stepper

A multi-step flow, `mat-stepper` styled by the Helix theme.

- Move with Next/Back buttons or the step headers; horizontal or vertical.
- The active step number uses `components-primary-filled`.

Consumer supplies: the steps, their content and (optional) per-step validation.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/stepper.stories.ts` (`Components/Stepper`). It shows the **Playground** story with that story file's controls.
