# Filters

Controls that refine large data sets by specific criteria, improving relevance of results. Active filters show as removable chips above the results.

**When to use** — any results view over a large set. From ~five filters, or hierarchical filters, move them into a **filter modal** or **filter panel** for usability.

Three documented forms: basic filters (inline), filter modal, filter panel.

Uses: Chip, Button, Select/Autocomplete, Dialog (modal), Table.
