# SortHeader

Sorting on a Helix table: `matSort` + `mat-sort-header` on `hlx-table`.

- Each header toggles ascending → descending → unsorted; an arrow shows the active column and direction.

Consumer supplies: the `matSort` directive and sortable column headers, wired to the data source.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/sort-header.stories.ts` (`Components/Sort header`). It shows the **Playground** story with that story file's controls.
