# Sidebar navigation

A column of links as the primary navigation, for products with subcategories under main sections. Unlike horizontal nav with dropdowns, a sidebar keeps subcategories visible.

**When to use** — when the product has nested sections; pair the shell's Header with a left `mat-sidenav`.

Variants in the docs: header with navigation and sidebar, nested navigation, and the products that work best with a sidebar.

Uses: Header, Sidenav, List, Footer.
