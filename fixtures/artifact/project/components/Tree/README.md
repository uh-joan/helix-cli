# Tree

A hierarchical list, `mat-tree` (with a `childrenAccessor`) styled by the Helix theme.

- With or without checkboxes; expand/collapse icons on parent nodes.

Consumer supplies: the nested data and node template. Use for genuinely hierarchical data (taxonomies, file trees).

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/tree.stories.ts` (`Components/Tree`). It shows the **Playground** story with that story file's controls.
