# ProgressBar

A `mat-progress-bar` styled by the Helix theme.

- **Determinate** — known progress, 0–100%. **Indeterminate** — ongoing activity.
- Track is `surface-contrast`, fill `components-primary-filled`. The Material 2 `color` input has no effect under Helix.

Consumer supplies: the mode and (determinate) value.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/progress-bar.stories.ts` (`Components/Progress bar`). The top example is its **All Modes** story; the Playground below has that story file's controls.
