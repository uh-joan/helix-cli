# DataGrid

Interactive grids for large data sets: AG Grid (`ag-grid-angular`) with the Helix AG Grid theme (`ag-theme-helix.css` from `@cdx/theme-ag-grid`).

- Use for sorting, filtering, virtualised scrolling and large volumes. For simple static data, use the Table.

Consumer supplies: the column defs and row data. The preview is a styled static table — the real grid is AG Grid, not Material.

Preview: static HTML rendition of the source styles; sample content is illustrative.
