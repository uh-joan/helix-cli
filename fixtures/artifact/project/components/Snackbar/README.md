# Snackbar

A brief message at the edge of the screen, opened with the `MatSnackBar` service and styled by the Helix theme.

- Dark `surface-invert` ground with `text-invert`; optional single action; auto-dismiss.

Consumer supplies: the message, optional action and duration. One line; one action.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/snackbar.stories.ts` (`Components/Snackbar`). It shows the **Playground** story with that story file's controls.
