# Divider

A `mat-divider` line separating components, sections or content.

- Orientation: horizontal (default) or vertical (`[vertical]="true"`).
- Inset variant indents the line to align with content.
- On a dark (inverse) surface use the invert colour (`.hlx-divider-invert`, `border-invert`).

Consumer supplies: placement and orientation. Keep dividers quiet — they use `border-secondary`.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/divider.stories.ts` (`Components/Divider`). The top example is its **Vertical** story; the Playground below has that story file's controls.
