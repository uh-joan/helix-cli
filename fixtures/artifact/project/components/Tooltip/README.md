# Tooltip

A plain text tooltip (`matTooltip`) that briefly labels a UI element — commonly an icon-only button.

- Container is `color-neutral-600` with `text-invert` (set by the Helix theme).
- For a title, links or buttons, use the Rich tooltip instead.

Consumer supplies: the text and the host element. Keep it to a few words.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/tooltip.stories.ts` (`Components/Tooltip`). It shows the **Playground** story with that story file's controls.
