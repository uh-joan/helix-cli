# List

A vertical group of text, icons or other elements for easy scanning, `mat-list` styled by the Helix theme.

- Types: static (`mat-list`), actions (`mat-action-list`), selectable (`mat-selection-list`, single or multiple).
- Options: 1–3 lines, leading/trailing icons, dividers, a subheader, disabled items.

Consumer supplies: the items and type. For tabular data use the Table or Data grid instead.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/list.stories.ts` (`Components/List`). The top example is its **Two Line** story; the Playground below has that story file's controls.
