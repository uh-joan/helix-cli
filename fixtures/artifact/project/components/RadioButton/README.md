# RadioButton

A `mat-radio-button` styled by the Helix theme, always in a `mat-radio-group` of two or more options where only one can be selected.

- Layout: column or row; label position after/before; group/option disabled; required.
- Selected dot is `components-primary-filled`.

Consumer supplies: the group label and options. Keep option labels short.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/radio-button.stories.ts` (`Components/Radio button`). It shows the **Playground** story with that story file's controls.
