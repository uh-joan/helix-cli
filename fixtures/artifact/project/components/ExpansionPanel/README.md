# ExpansionPanel

An accordion of `mat-expansion-panel`s grouped in a `mat-accordion`, styled by the Helix theme.

- Each header shows a toggle icon at its end for expanded/collapsed state.
- Panels use `surface-primary`, `border-radius-default`, `elevation-sm`.

Consumer supplies: the panel headers and content; set whether multiple can open at once.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/expansion-panel.stories.ts` (`Components/Expansion panel`). It shows the **Playground** story with that story file's controls.
