# Select

A dropdown choice in a `mat-form-field`, `mat-select` styled by the Helix theme.

- Appearance: `fill` or `outline`; density sets the height.
- Options may be grouped (`mat-optgroup`), multiple, required, individually disabled; supports a leading icon, hint and error.

Consumer supplies: the label and options. The open panel reuses the menu surface.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/select.stories.ts` (`Components/Select`). The top example is its **Matrix** story; the Playground below has that story file's controls.
