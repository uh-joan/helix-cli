# ProgressSpinner

A `mat-progress-spinner` styled by the Helix theme. Helix mainly uses the **indeterminate** mode; for a known duration use a progress bar.

- Ring track `surface-contrast`, indicator `components-primary-filled`. The Material 2 `color` input has no effect under Helix.

Consumer supplies: the mode, diameter and (determinate) value.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/progress-spinner.stories.ts` (`Components/Progress spinner`). The top example is its **In Button** story; the Playground below has that story file's controls.
