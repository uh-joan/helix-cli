# SkeletonLoader

Placeholder shapes shown while content loads, built with `ngx-skeleton-loader`.

- Configure the shape with `appearance`, the motion with `animation`, and the dimensions with `[theme]` (any CSS).
- Uses `surface-minimal` for the placeholder fill.

Consumer supplies: the shapes that mirror the real content's layout.

Preview: live — the real Angular component with the shipped Helix theme, rendered from the Storybook stories in `packages/storybook/src/stories/skeleton-loader.stories.ts` (`Components/Skeleton loader`). The top example is its **Composition** story; the Playground below has that story file's controls.
